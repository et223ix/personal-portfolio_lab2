Function descriptions:

- Name validation: Checks that the Full Name field isn't empty, contains at least two characters and uses allowed characters.

- Email validation: Checks that the email field is not empty, and that the entered email address is achieving the criteria for a valid email address.

- Topic selection: Requires the user to select a topic from the drop down menu.

- Comment validation: Requires a minimum of 15 characters. 

- Live character counter: Updates the character count as the user types and changes its text colour to indicate whether the minimum lenght has been reached. 

- Optional website URL: Allows the user to leave the URL field empty but validates it if a URL is entered according to the criteria of the URL format 

- Visual validation feedback: Displays error messages and uses borders to indicate invalid and valid fields. 

- Clear button: Resets the form fields, error messages, field styling and character counter. 

- Submit button: Validates the form and displays a personalised success message when all fields are valid. The message disappears automatically after four seconds. 

- Responsive design: Adapts the feedback form to both desktop and mobile devices. 


Explanation on how to run the site:

- Download the project files
- Open the project folder in Visual Studio Code
- Open feedback.html using Live Server
- The website will open the browser, where the feedback form can be tested.
